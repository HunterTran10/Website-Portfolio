# Hunter Tran Portfolio

Personal portfolio site built with React and React Bootstrap, showcasing my projects, skills, and background as a frontend developer.

🔗 **Live site:**  [huntertran.vercel.app](https://huntertran.vercel.app)

## Built With
- React
- React Bootstrap

## Features
- Responsive design with dark theme
- Scroll navbar behavior with dynamic styling
- Lightbox modal for project screenshots
- Reusable components (NavBar, Banner, Skills, Projects)

## Running Locally
```bash
git clone https://github.com/HunterTran10/Website-Portfolio.git
cd Website-Portfolio
npm install
npm start
```
